About these measurements

Resets on reload or a new document. SPA navigation keeps the same totals. Durations cover completed request chains, including redirects, download time, and authentication waits; failed requests are excluded.

Sizes total available Content-Length values from final, completed, non-cached responses. They exclude headers, intermediate redirects, failed downloads, and WebSocket traffic; this is not total network usage.
